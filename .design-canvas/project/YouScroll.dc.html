03 / Where it runs

One site.One settings object.

No YouScroll account, analytics service, advertising SDK or developer-operated server. The build fails if a host pattern ever escapes youtube.com.

Local-first, deliberately narrow.

The extension makes no network requests of its own and contains no remote code. The only thing it stores is a small settings object: which features are switched on, and which tab the panel opens on.

The panel and the pop-out button are ordinary elements in the page, so scripts running on that page can see them, exactly as they can see the rest of the page.

Read the privacy policy
Host access
https://www.youtube.com/* only — to move YouTube’s own comments and recommendations into the panel, and put them back.
Storage
chrome.storage.sync holds one settings object, synced through Chrome’s own sync if you are signed in.
Reads
One piece of text: the comment count, shown on the panel’s tab label. Not stored, and it does not leave the page.
Not used
No background service worker, no tabs or scripting permission, and no optional permissions.

04 / Good manners

It steps aside, on purpose.

Every change YouScroll makes carries its own undo. Switch a feature off and YouTube’s layout returns exactly as it was.

01

Theater mode and fullscreen

YouTube reflows into one wide column, so the panel stands down. Press t or leave fullscreen and it comes back.

02

Narrow windows

Below YouTube’s own two-column breakpoint you get stock YouTube instead of a half-applied layout. Widen the window past roughly 1020 pixels.

03

No comments to pin

Videos with comments disabled, and live streams, which show a chat panel instead of comments.
